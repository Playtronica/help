## Logic Pro (macOS)

1. **Plug the Playtronica device into your Mac** with a USB cable.
2. **Open Logic Pro.** Logic detects new MIDI devices automatically. You should see a "New MIDI device detected" notification. If not, check Audio MIDI Setup (see [Connect your device to a computer](/software/connecting/)).
3. **Create a Software Instrument track.** Go to File → New Track → Software Instrument and choose any instrument.
4. **Make sure the track is selected.** Logic routes all incoming MIDI to the selected track automatically. No further configuration is required.
5. **Touch the device.** The notes play through the chosen instrument.

## GarageBand (macOS)

1. **Plug in the device** and open GarageBand.
2. **Create a new project and add a Software Instrument track.**
3. **GarageBand detects the MIDI device automatically.** Select the track and play.

## GarageBand (iOS)

1. **Connect with a Lightning to USB or USB-C to USB-A adapter.** This adapter is not included in the box.
2. **Open GarageBand on iOS.** Create a new song and choose any instrument.
3. **Tap the settings icon → Advanced → Enable MIDI.** Your Playtronica device appears in the input list.
4. **Touch the device.** The notes play through the iOS instrument.
