## Use multiple devices at once

Each Playtronica device has a unique USB identity. You can run several devices at the same time. In Ableton, or in any MIDI-routing tool (MIDI-OX on Windows, Patchwork on macOS), each device appears as a separate MIDI input. Assign each device to a different instrument, effect chain, or visual trigger.

## Installation setup tips

- **Use USB hubs with individual power switches** for reliable power management. A powered USB hub with its own power adapter is more stable than a passive hub.
- **Test every alligator-clip connection before opening.** Humidity changes affect conductivity. Re-test on the day.
- **For long-running installations**, route MIDI into a dedicated laptop running Ableton in performance mode. Disable the screensaver. Disable sleep.
- **Lower sensitivity during busy hours** if Biotron is part of the installation. Crowd interference can trigger false notes.
- **Schedule preset changes through the day** using SysEx on Biotron. See [Biotron Advanced](/devices/biotron-advanced/).

## MIDI routing and custom instruments

Playtronica devices send standard MIDI — Note On, Note Off, velocity, and optional Continuous Control. This means they work with any MIDI-capable software: Max/MSP, Pure Data, SuperCollider, TouchDesigner, Resolume, Ableton, and many others. The creative ceiling is effectively unlimited.
